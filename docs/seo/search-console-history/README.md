## Czym te pliki są, a czym nie są

Migawki to **streszczenia historyczne**, nie kompletny eksport danych. Search Console pomija zapytania rzadkie i wrażliwe, zwraca wiersze najwyższe zamiast pełnego zbioru i ma ograniczony okres retencji. Do kompletnego przechowywania na poziomie wierszy właściwym narzędziem jest baza danych lub eksport zbiorczy.

Istniejących migawek **nie wolno nadpisywać** — historia ma pozostać nienaruszona.
